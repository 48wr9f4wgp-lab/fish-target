# V34 標準戻る・進むの統合

Scope: title-local / R02 navigation history
PRODUCTION_DECISION=UNDECIDED / RELEASE_APPROVAL=NOT_REQUESTED

## 目的・実装

ホーム・結果・FIELD・保存の画面と、タックル・持ち物ダイアログをブラウザ履歴と連動させる。
専用 `navigation-history-v34.js` を既存拡張の後に読み込み、build/SWにも含める。既存render関数へのwrapper追加はない。

- 主要画面・魚・ダイアログが変わったときだけ履歴を追加。同一画面の検索・条件変更は現在の履歴へ反映。
- アプリ内の戻る/閉じるが直前の履歴と一致する場合は、その履歴を消費。同じ戻り先を追加しない。
- 戻る/進むとreloadで魚・釣法・条件を復元。ホームでは検索・フィルタ・一覧位置も復元。
- 手持ち道具や梱包済み状態を履歴へコピーしない。既存の保存データと判定処理を使う。
- ダイアログ往復時は不要な本体再描画を避け、未登録入力を同じページ内で保持。既存focus管理で閉じる。
- 不正・旧履歴はホームへ安全に復帰。初期履歴は置換し、サイトからの通常の戻るを妨げない。
- 新しい永続保存キーやURLパラメータは追加しない。釣法・推奨データを変更しない。

## 受入・検証

新規ブラウザ検査: 魚→釣法変更→FIELD→標準戻る→進む→アプリ内戻る→ホーム→進む、タックルの標準戻る/進むと入力保持、結果reload、持ち物の戻る/進む、不正履歴、前のページへ退出。
ChromiumとWebKitの既存CIへ追加。Chromiumで新規検査と既存操作性検査が成功。単体358件成功。正確な最終headのCI判定はPR #65に記録。

## 限界・残件

- 物理iPhoneのスワイプ戻り・ホーム画面PWAは未確認。
- 同一ページ内の未登録入力は保持するが、未登録入力の再読み込み後の復元・下書き永続保存は今回追加しない。
- 全画面の文字拡大/コントラストは次のR03。
- 前回WebKit終了の根本原因は未確定。診断追加後のbaselineでは5系統成功し、通常回帰で監視する。
