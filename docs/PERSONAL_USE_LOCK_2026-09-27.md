# FISH TARGET / 個人専用の確定方針

Status: **LOCKED / 確定**
Decision date: 2026-09-27
Decision source: ユーザーの明示指示「このアプリは俺個人用として固定する」
Machine-readable intent: `build.config.json` -> `productIntent`
Scope: FISH TARGET only. 一般の釣り支援アプリであり、ゲーム開発の公開工程は適用しない。

## 目的

本人の釣り準備・道具選び・釣行時の判断を、iPhoneで少ない操作で行えるようにする。
魚種からの診断だけでなく、道具比較・手持ち管理・釣行条件・持ち物確認を独立して使える構成を維持する。

## 対象外へ変更する工程

App Store申請、一般ユーザーへの配布、収益化・広告、会員機能・複数ユーザー、集客・継続率の最適化は対象外。
全メーカー・全魚種・全価格の網羅を完成条件にしない。本人が使う用途から必要なデータを追加する。
一般配布を前提とした素材・商品データの公開承認取得を、個人用の機能改善の必須完了条件にしない。

既存の公開用資料・R04以降の計画・過去の監査記録は履歴として保持する。ただし公開目的を前提とする工程の優先順位・必須扱いはこの決定で上書きする。操作性や正確性に関する残件まで完了扱いにしてはならない。
将来の一般公開・収益化は、ユーザーがこのLOCKを明示的に変更するまで再提案・再実装しない。

## 残す完了条件

- 本人の主要導線が起動・操作・復帰でき、手持ちや保存済みプランを破壊しない。
- 仕様・価格・単位・出典・確認日を区別し、未確認を0や性能劣位として扱わない。
- 小画面の視認性と操作性を確認し、物理iPhoneでの実機結果を別途記録する。
- オフライン、読込失敗、保存失敗からの復旧を確認し、未検証を明示する。

## 個人用途とアクセス制限は別

この設定は製品の目的を固定するもので、認証・アクセス制限を追加するものではない。
2026-09-27のGitHub API確認ではリポジトリは `public`。現在のPagesサイトに本人限定アクセスがあることは未検証。
本変更は既存サイトを非公開化せず、サイトを更新・停止・移設もしない。コードの公開設定と本人限定の配信方法は別途判断する。
本人の実際の位置・所持品・アカウント情報等をソースやCI成果物へ書き込まない。

出典と利用条件の記録は保持する。個人用という決定から、第三者素材の権利取得や外部サービスの利用許可を推定しない。
`FISH_TARGET_PUBLICATION_BUILD=1` と既存のpublication隔離テストは、一般公開に進む工程ではなく、研究用データが配布経路へ漏れないことを確認する回帰テストとして残す。
