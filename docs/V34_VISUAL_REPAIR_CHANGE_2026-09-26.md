## Goal

ブリ・ワラサ、ニジマスの既存の識別特徴を保ちながら、Art Bible の右向き・透過背景に揃える。
390px のカードに白い矩形を出さず、375 / 430px とオフラインでも同じ素材を表示する。

## Scope

- 内蔵画像生成で既存のプロジェクト生成画像を編集し、別名の開発確認用素材として保存。
- 画像の出典、入力・出力ハッシュ、プロンプト、生成方法、確認状態を記録。
- 開発確認用の素材選択・ビルド組込みと、公開ビルドへ混入しない契約を実装。
- 実画像のデコード・透過・表示枠・向き・端末幅での見え方を確認。

## Existing behavior / non-goals

現行素材は白背景・左向き。既存の公開用素材と承認状態を保存する。
隔離済みBatch 2を復活させない。魚種数や商品SKU数の増加、全体UI変更、公開操作は今回の対象外。
画像の生成・自動検査だけで、ユーザーの魚種・美術承認を取得した扱いにしない。

## Acceptance / tests

1. 2素材を個別に生成し、全身と識別特徴を確認。透過を実デコードで確認。
2. 開発版では2素材を表示。公開版には新素材を配布せず、従来素材を使用。
3. モバイル幅3種でカードと詳細のクリップ・白枠を確認。
4. 既存画像、キャッシュ更新、オフライン、公開ビルドの回帰を確認。

## Recovery

既存4素材のバイト列と正本authoringを保持。開発用選択を外すことでbaseline表示に戻せる。
新素材のユーザー確認は未実施として記録し、配布・マージは別の承認対象とする。

## 実装結果

- ブリ・ワラサとニジマスの2点を内蔵image_genで編集。頭を右向きにし、白背景を透過。
- `fish-preview-v34-buri-warasa.webp` / `fish-preview-v34-nijimasu.webp`。元のPNG寸法1536×1024を維持し、WebPへ符号化。追加容量は合計約344KiB。
- 生成プロンプト全文・入力/生成/出力SHA-256: `authoring/fish-visual-repair-v34.json`。
- 描画時の縮尺を0.88にして全身の余白を確保。画像の切抜きや手動の魚体描き替えはしていない。
- 正本の公開用4素材は変更なし。開発画面の現行素材は確認待ち2点＋従来の権利確認済み2点。公開ビルドは元の4点。
- authoringの独立した `development_previews` が開発版のみで選択される。出典・hash・未承認状態を検証し、同名重複や元ファイルの上書きを拒否。
- 隔離済みBatch 2の8点は引き続きランタイム・配布対象外。
