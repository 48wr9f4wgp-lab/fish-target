## 4. 見た目について残る課題

- 先行4点と既存画像で背景の見え方が不揃い。390pxの実画面で白い矩形が確認できる。
- 先行の通常魚（ブリ・ワラサ、ニジマス）は左向きで、Art Bible の右向き指定と一致しない。
- `publication_ready` は現在、権利情報と出力整合の技術条件。美術・魚種同定の承認を代行しない。
- 新しい写実調素材の制作・魚種同定・390pxでの判断を経てから置き換える。隔離した素材を無条件に復活させない。

## 5. 検証証拠と限界

- `npm test`: 生成物契約、保存移行、更新キャッシュの回帰を含む。
- `scripts/rc-browser-suite.mjs`: 操作・表示・保存・公開用ビルドの Chromium 回帰。

- ローカル環境では WebKit 用共有ライブラリが不足するため、WebKit の成否は GitHub CI の対象 head を根拠とする。
- 前回の順序テスト修正は、同一フレーム採寸＋DOM順検査として妥当。ただし元のCI失敗を直接再現していないため「smooth scrollが原因と完全確定」とした前回表現は強すぎた。
