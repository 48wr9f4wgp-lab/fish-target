# RC Product Quality v32 Plan

Goal: make the first-use path understandable with minimal reading on iPhone/Safari/PWA.

Target loop:
Fish → Method → FIRST CAST → AUTO BUILD → FIELD MODE

Product-quality gates:
- clear next action at every step
- primary actions visually dominant
- secondary explanations collapsed or visually de-emphasized
- 44px+ practical touch targets on phone
- no horizontal overflow at 390px baseline
- no change to fish/method recommendation semantics
- no MY TACKLE save-schema mutation
- no Catalog rights/publication weakening
- no main/public deployment

Implementation scope:
- result CTA hierarchy
- FIRST CAST emphasis and reduction of redundant copy
- AUTO BUILD placement/emphasis after FIRST CAST
- FIELD MODE transition clarity
- focused browser QA for first-use progression

Out of scope:
- new fish/method content
- new Catalog data
- monetization/live features
- public deploy
